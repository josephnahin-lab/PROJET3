QUESTIONS PRATIQUES

Avant de commencer.

Quelques repères pour démarrer et comprendre les limites de la démonstration.

Comment accéder à mon espace ?＋

Cliquez sur « Accéder à mon espace », puis choisissez Médecin ou Administrateur. Chaque choix ouvre sa page dédiée.

Les profils et les envois sont-ils déjà créés ?＋

Non. Le projet commence sans profil ni soumission préenregistrés. Vos utilisateurs saisissent les informations nécessaires.

Les données sont-elles partagées entre appareils ?＋

En démonstration locale, les données restent dans le navigateur utilisé et les photos ne sont pas partagées entre les pages. Pour une synchronisation entre utilisateurs, configurez le mode Supabase.

Peut-on utiliser de vraies ordonnances dès maintenant ?＋

Non. Ce prototype n’est pas validé pour des données médicales réelles. Faites vérifier la sécurité, l’hébergement, les accès et la durée de conservation avant tout usage réel.
